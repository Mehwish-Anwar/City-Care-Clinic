# MediTrack SRS Validation Checklist (v0.1)

| ID | Item | Answer | Evidence | Where question came from |
| :--- | :--- | :--- | :--- | :--- |
| CL-001 | Does each requirement contain only one "shall" or "may" statement? | | | Rule: Clear |
| CL-002 | Is every requirement free of undefined vague words (e.g., "quickly", "user-friendly", "securely", "normal", "policy")? | | | Rule: Clear |
| CL-003 | Does every speed or time requirement state a number with a unit? | | | Rule: Testable |
| CL-004 | Could a pass/fail test be written for every requirement? | | | Rule: Testable |
| CL-005 | Are all appointment duration rules free of contradictions? | | | Rule: Free of contradictions |
| CL-006 | Does the document define what happens when a reminder fails to reach a patient? | | | Rule: Complete |
| CL-007 | Does the document specify how the system stops two users from booking the exact same time slot? | | | Risk: Double bookings |
| CL-008 | Does the document state how many minutes before an appointment a reminder is sent? | | | Risk: Forgotten appointments |
| CL-009 | Does the document define a cutoff time before an appointment after which online cancellation is blocked? | | | Risk: Late cancellations |
| CL-010 | Does the document specify how many concurrent users the system must support during Monday morning peak hours? | | | Risk: Monday morning rush |
| CL-011 | Does the document state a backup plan if the online system goes offline during clinic hours? | | | Risk: System downtime |
| CL-012 | Does the document state how a patient receives confirmation after booking an appointment? | | | User: Patient |
| CL-013 | Does the document state whether doctors can block off unavailable time slots on their schedule? | | | User: Doctor |
| CL-014 | Does the document specify how emergency walk-in patients are given priority over routine bookings? | | | User: Receptionist |
| CL-015 | Does the document state how a clinic administrator adds new doctors to the system? | | | User: Clinic administrator |
| CL-016 | Does the document specify which user roles may view a patient's medical record? | | | User: Data protection officer |
| CL-017 | Does the document specify accessibility features (such as large text or screen reader support) for elderly patients? | | | Risk: Elderly patients excluded |
| CL-018 | Does the document define the exact "clinic policy" rules for handling overdue payments? | | | Rule: Complete |
